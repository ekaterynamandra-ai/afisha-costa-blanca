В сообществе [aipack.live](https://www.aipack.live/courses) мы с мужем собрали 5 курсов и продолжаем добавлять. Часто спрашивают: «с чего начать?» — потому что глядя на список из ChatGPT, n8n, Claude Code и Codex, легко зависнуть в выборе.

Вот короткий разбор каждого + матрица «если ты X — начни с Y».

## Курсы — что внутри

### 1. ChatGPT с нуля — 8 уроков
**Для кого:** не пишешь код, но хочешь использовать AI как помощника каждый день — для работы с текстом, документами, идеями, рутиной.

**Что внутри:** настройка Projects, работа с промптами по делу (а не «составь мне универсальный промпт-шаблон»), Deep Research для глубокого ресёрча, Canvas для совместной работы над документами. К концу курса ChatGPT перестаёт быть «вау-игрушкой» и становится рабочим инструментом.

### 2. N8N автоматизации — 10 уроков
**Для кого:** хочешь автоматизировать процессы без кода — связать почту, Telegram, CRM, базы данных, AI в одну рабочую цепочку.

**Что внутри:** основы n8n, триггеры, ноды, обработка ошибок. Финальный проект — Telegram-бот с AI-агентом, который отвечает на сообщения и подключается к внешним сервисам. Это самый «прикладной» курс — каждый урок собирает реальную автоматизацию.

### 3. Claude Code + Вайбкодинг
**Для кого:** хочешь создавать продукты, MVP, сайты, инструменты — даже если ты не программист. AI берёт на себя написание кода, ты говоришь на естественном языке.

**Что внутри:** Claude Code как разработчик-помощник, цикл «идея → промпт → итерация → готовый продукт». Это про мышление «вайб-кодера» — когда ты не пишешь код, а **формулируешь задачи** на естественном языке.

### 4. Codex: AI-агент от OpenAI
**Для кого:** уже умеешь немного программировать и хочешь полностью встроить AI в свой workflow.

**Что внутри:** установка, скиллы Codex, плагины, генерация изображений, интеграция с Claude Code. Самый «продвинутый» из курсов — для тех, кто уже понимает зачем ему AI-агент и готов выжимать из него максимум.

### 5. Твой путь — маршрут до первого клиента
**Для кого:** хочешь не только освоить AI, но и **зарабатывать** на нём — найти заказчиков, упаковать услугу, запустить первый платный проект.

**Что внутри:** пошаговый чеклист от первого запуска до реальных проектов с клиентами. Это «обвязка» вокруг технических курсов — что делать после того, как научился.

## Что в работе (скоро)

- **OpenClaw** — AI-агент для управления задачами через Telegram и WhatsApp. Для тех, кто хочет интегрировать AI в личный/командный workflow без сайтов и приложений.
- **Продвижение и продажи** — AI-инструменты для маркетинга и поиска клиентов.

| Если ты… | Начни с |
|---|---|
| Не программист, хочешь использовать AI ежедневно | **ChatGPT с нуля** |
| Хочешь автоматизировать рабочие процессы без кода | **N8N автоматизации** |
| Хочешь создавать сайты / приложения / MVP с помощью AI | **Claude Code + Вайбкодинг** |

| Хочешь сделать AI своей профессией | **Твой путь** + любой из технических курсов параллельно |
| В сомнениях, хочешь сначала «понюхать» | **ChatGPT с нуля** — самая низкая точка входа |

## Как выстроить маршрут

**Сценарий A — освоить инструмент для работы.** ChatGPT с нуля → N8N → готово. Достаточно, чтобы экономить часы в неделю.

**Сценарий B — стать AI-практиком, делать продукты.** ChatGPT с нуля → Claude Code → Codex. Финал — собственное приложение или внутренний инструмент.

**Сценарий C — превратить AI в источник дохода.** Любой технический курс (ChatGPT / N8N / Claude Code) + **Твой путь** параллельно. К концу — первые клиенты.

Самая частая ошибка — пытаться сразу пройти всё. Возьми **один курс**, доведи до конца, сделай реальный проект из него, и только потом переходи к следующему.
