# User Journey — от посетителя до покупателя

Модель kateinspain.es (уточнена 2026-07-08): **только инфопродукты**. Никаких консультаций, никакого paid TG. Free-контента много → лид-магниты собирают email → email/TG прогревают → покупка платного продукта.

## Три точки входа

Читатель приходит по-разному. Каждая точка ведёт к одному месту (лид-магнит), но копия и первый экран разные:

| Откуда пришёл | Что видит первым | Куда ведём |
|---------------|------------------|------------|
| **Из Google** («ипотека в испании иностранцу») | Статья на сайте | Внизу статьи — bar «Хочешь расширенную версию и калькулятор? → Ипотека Pro» + «Взять базовый чек-лист бесплатно» |
| **Из Instagram/TG** | Homepage | Крупный hero-CTA «С чего начать» → пейдж с базовым чек-листом (email-gate) |
| **Прямая ссылка на продукт** | Landing одного продукта | Сразу checkout Gumroad или «Забрать базовый чек-лист бесплатно» |

## Free → Paid: где precisely лежит порог

**Free всегда:**
- Все 43 evergreen-статьи на сайте
- Ежедневный TG-канал
- Базовый чек-лист (сокращённая версия)
- Ипотечный калькулятор view-only

**За email (Tier 0 lead magnet):**
- Базовый чек-лист в PDF-формате
- Editable копия ипотечного калькулятора (не расширенная, простая версия)

**Платно (Gumroad):**
- **Ипотека Pro €15** — расширенный калькулятор с инвест-логикой + PDF-гайд «что ожидать» на основе Катиного опыта
- **Autonomo Pro €19** — калькулятор доходов с фактурами для 3 рынков + PDF-подсказки
- **Apps Pack €15** — гайд по ~50 испанским приложениям (что скачать, что настроить, что где хранить)
- **IB Pro €25** — инвестиции через Interactive Brokers из Испании (открытие счёта, депозиты, первый портфель, налоги)
- **Первый год €39-49** — расширенный чек-лист по всем 10 разделам с деталями/шаблонами/скринами документов (включает раскрытые тебя темы: машина/права/техосмотр, медицина, прописка)

## Формула ценности каждого платного

Ключ (по memory `feedback_kate_analyst_not_lawyer`): **аналитика > закон**. Клиент готов заплатить не за пересказ инструкций (это гуглится), а за:

1. **Твой опыт как факт**: «я делала X, потратила Y, вот что не работало»
2. **Числа и логика**: калькулятор считает то, что вручную считать долго и с ошибкой
3. **Investment-угол**: даже бытовое (ипотека, autonomo) через призму «выгодно ли это, если посмотреть на 5-10 лет?»
4. **Готовые шаблоны**: скачал → вставил свои цифры → работает

## Метрики успеха этой модели

- **Conv лид-магнит**: 8-15% посетителей сайта → email
- **Conv email → продукт**: 3-8% подписчиков покупают Tier 1
- **Средний чек**: €20-30 (Tier 1) → €39-49 (Tier 2)
- **LTV**: €50-100 (если человек берёт Tier 1 + Tier 2)

Kill-switches (когда убиваем продукт) — см. `docs/research/2026-07-monetization-summary.md`.

## Открытые вопросы к Кате

1. **Названия блоков на сайте** — «Мои шпаргалки» плохо. Варианты: «С чего начать» / «Полезное» / «Твой набор» / «Начни отсюда» / что-то своё?
2. **Порядок запуска 5 платных**: с какого начнём (M3 сентябрь)? Ипотека готовее всего (Sheet + пост есть), Apps Pack самый простой в сборке, IB Pro требует твой личный опыт.
3. **Playbook «Первый год»** — согласна что это == расширенный чек-лист (один продукт, не два)? Внутри разделы: документы / финансы / медицина / жильё / транспорт (машина+права+ITV+школы) / дети / питомцы / быт / интеграция.
4. **Цены** — вилки: €15 / €19 / €15 / €25 / €39-49. Ощущаешь как «дороговато/дёшево/норм»?
5. **IB Pro** — у тебя есть открытый счёт в Interactive Brokers и опыт инвестирования? Если да — делаем с реальными цифрами. Если нет — либо переносим, либо теоретическую версию.
6. **Права DGT в чек-листе**: пометить как «применимо только пока действует временная защита украинцев» и обновлять при изменении?
