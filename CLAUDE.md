## Доступные команды

- **`/test_mode`** — тестировать автопубликацию через личку админа
- **`/preview`** — создать HTML-превью постов на неделю (в content/drafts/)
- **`/approve <week>`** — одобрить план на неделю (поставить `approved: true`)
- **`/publish_now <id>`** — опубликовать конкретный пост вручную сейчас
- **`/status`** — показать статус всех постов в расписании
- **`/digest <month>`** — создать месячный дайджест по неделям

## Правила работы

### Формат v7 (с 04.07.2026) — 4 поста/неделю с чёткими ролями

| День | Роль | Тип контента |
|------|------|--------------|
| **Пн** | Новость иммигрантам | Изменения в ВНЖ, документы, налоги, законы (extranjería, BOE, expat-каналы) |
| **Ср** | Топ-подборка на выходные | 3 варианта разных вайбов: событие / атмосферное / с детьми |
| **Пт** | Evergreen полезное | Личный опыт Кати (жизнь, комфорт, работа, бизнес). Легче ипотеки |
| **Вс** | «Что делать в Испании» | Сезонная рубрика по периодам года — для новичков |

Всё от первого лица — Катя рассказывает как строит здесь жизнь: безопасно, комфортно, заработок/работа/бизнес.

### Контент-политика (v6 запреты сохраняются)
- НЕ публиковать без явного одобрения
- НЕ сравнивать Испанию с СНГ (политическая зона)
- НЕ разбирать легализацию/ВНЖ как тему (кроме конкретных новостей об изменениях)
- НЕ рекламировать частный бизнес (отели, рестораны, частные школы)
- ДА: гастро-фестивали, парады, бесплатные семейные события, природа, рынки, массовые парки (Terra Mítica, Aqualandia)
- Все локации — Google Maps ссылки
- Каждый пост = ОДНО сообщение photo+caption (не разделять), visible-text ≤ 1024 символа
- Каждое фото = landscape 16:9, не вертикаль/квадрат
- Мониторинг источников новостей для пн-поста — `knowledge-base/immigrant-news-sources.md`
- База знаний событий — `knowledge-base/events.md`, `knowledge-base/places.md`

### Тайминг публикаций (v7)
- Пн 10:00 — новость иммигрантам
- Ср 10:00 — топ-подборка на выходные (не вечер — люди должны успеть спланировать)
- Пт 10:00 — evergreen полезное
- Вс 10:00 — что делать в Испании
- Все времена — испанское (Europe/Madrid)

### Перед публикацией всегда
1. Показать превью HTML
2. Дождаться одобрения пользователя
3. Поставить `approved: true` в week*.json
4. GitHub Actions опубликует автоматически

## Скрипты

- **autopublish.py** — публикует посты по расписанию (status=approved + время наступило). Запускается через GitHub Actions раз в 2 часа.
- **publish_telegram.py** — ручная публикация одного поста.

## Cron расписание (UTC → CEST испанское)
- 06:00 UTC = 08:00 CEST (рынок утро)
- 08:00 UTC = 10:00 CEST (утренние посты)
- 12:00 UTC = 14:00 CEST (дневные)
- 16:00 UTC = 18:00 CEST (вечерние)
